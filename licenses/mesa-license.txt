Mesa 3D Graphics Library — license and copyright

Where Clicker ships Mesa, it is in the mesa\ directory beside the executable —
opengl32.dll and libgallium_wgl.dll, unmodified, replaceable with any
compatible build, and loaded only when this program is drawing with the
software renderer. That is the x64 Windows installer; the arm64 one carries
this notice and no Mesa, because the distribution used publishes no
Windows-on-Arm build. The driver it is here for is llvmpipe, which rasterises
on the processor.

Three things follow. First, Mesa's own license page, verbatim, as published at
https://docs.mesa3d.org/license.html. Second, Mesa's default license grant,
which is the MIT license the page names, with the copyright notice MIT
requires be carried with every copy. Third, a note on what else is inside these
binaries.

Individual files in Mesa may carry their own license, named by an SPDX
identifier in the file itself, and the full set of texts lives in the licenses/
directory of Mesa's source tree at https://gitlab.freedesktop.org/mesa/mesa.

llvmpipe links LLVM, whose license is beside this file in llvm-license.txt.

What else is inside these binaries.

libgallium_wgl.dll is built with LLVM compiled into it, which is why LLVM's
license is beside this file in llvm-license.txt. A Mesa build of this kind also
statically links other permissively licensed components — zlib, the SPIRV
tooling, the Khronos GL and WGL headers among them — each under its own terms,
which are collected in the licenses/ directory of the Mesa source tree named
above. Nothing in it is copyleft.
